# actividad01_hello_docker

App Spring Boot ("Hello!" en `/hello`) con un script Bash (`gestor.sh`) y un `Dockerfile`.

## Uso

```bash
chmod +x gestor.sh mvnw
./gestor.sh
```

Requisitos: Java 17 y Docker. Orden recomendado en el menú: 2 (compilar), 3 (imagen), 4 (contenedor). Probar en http://localhost:8080/hello
